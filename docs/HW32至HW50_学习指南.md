## 按函数走一遍

在 `TestHW43()`、`RenderHW43()` 设置断点，再按 F11 进入共享算法：

```text
wWinMain / wmain
  → ParseArguments → InitializeApplication
  → RunMathHomeworkTest → TestHW43 → MathTestContext（实际值/预期值/结果）
  → RenderApplicationFrame → RunHomework → RenderHW43
       → CoarseSphere（缓存几何）
       → Render（设置相机、RenderTarget、材质）
       → RenderLearning::DrawMesh
           → Model 顶点与世界法线
           → P × V × M × Position
           → 原 ClipTriangleToFrustum（同步裁剪位置、颜色、法线、UV）
           → PerspectiveDivide → ViewportTransform
           → RasterizeAttributedTriangle
               → 包围盒限制在目标内 → CoveredSample / Top-left
               → NDC 深度线性插值 → [0,1] → 深度比较
               → InterpolateAttributes（透视校正）
               → BlinnPhong（Phong 模式在片元计算光照）
               → 保存样本颜色和深度
       → Resolve → Publish（显示编码、中文面板）
  → WM_PAINT 显示当前画布
```

所有新章节都使用这一组共享图像/几何/着色算法。HW32、33、34、47、49 主要是信号或图像实验，直接计算图像并发布。HW36、37 为精确观察覆盖规则，直接提供屏幕位置和 NDC 深度进入光栅化；HW35、38～46、48、50 从 Mesh 经 MVP 和裁剪进入光栅化。

原 HW31 仍使用原 `RasterizeTriangle3D()` 与 100×100 帧缓冲。新的属性光栅化用于动态分辨率、法线、UV 与四样本实验，复用原数学、裁剪、深度比较及 Top-left 判定。这使原章节图像可以逐像素回归，同时可以学习新增属性流程。

## 关键公式与手算例子

### 采样、卷积与抗锯齿（32～37）

- 正弦采样：`s[n]=sin(2π f n/fs)`。3 Hz 在 4 Hz 采样，`n=1` 得 `sin(3π/2)=-1`。采样率需高于最高频率两倍才能避免一般情况下的混叠；刚好等于两倍有相位等边界问题。
- 真卷积：`g[x,y]=Σ K[i,j] I[x-i,y-j]`，核以中心为原点。Gaussian 核 `(1,2,1)ᵀ(1,2,1)/16` 的权重和为 1，单位脉冲中心输出为 `4/16=0.25`。
- SSAA：每个高分辨率位置完整执行覆盖、深度和着色，再平均。红绿蓝白四像素均值为线性 RGB `(0.5,0.5,0.5)`。
- 四样本覆盖与深度：偏移 `(0.25,0.25)`、`(0.75,0.25)`、`(0.25,0.75)`、`(0.75,0.75)`。NDC `z=-0.4` 对应深度 `0.3`，小于远面 `z=0.6` 的深度 `0.8`。每样本单独测试，最后平均四份颜色。
- 共享边：CCW 三角形内部边值为正。边值为零时仅接受 `dy<0 || (dy==0 && dx<0)` 的边，这与工程原屏幕坐标约定一致。相邻两面只有一面接收同一边界样本。

### 法线与着色（38～44）

- 面法线：`normalize((B-A)×(C-A))`。顶点法线累加未归一化面叉积后再归一化，叉积模长等于两倍三角形面积，形成面积加权。
- Lambert：`baseColor × (ambient + diffuse × max(0,n·l))`。材质 0.5、环境 0.1、漫反射 0.8，正对光得到 0.45，背光得到 0.05。
- Blinn-Phong：`h=normalize(l+v)`，加 `specular × max(0,n·h)^shininess`；背光不加高光。指数增大，高光变窄。
- Flat 在面心按面法线算一次光照；Gouraud 在三个顶点算光照后插值颜色；Phong 插值位置和法线、归一化后在片元算光照。**Phong 着色方式和 Blinn-Phong 光照公式是两个不同层面的概念。**
- 法线矩阵：`N=inverse(A)ᵀ`，A 是 Model 左上 3×3。因为 `n·t=0`，希望 `(Nn)·(At)=0`，所以需要逆转置。`A=diag(2,1,1)` 时，法线 `(1,1,0)` 应变为 `normalize(0.5,1,0)`；平移不参与。零尺度导致奇异矩阵，明确报错。

### UV 与过滤（45～50）

- UV 的 V 向上，图像行号向下。texel 中心位置：`s=u×width−0.5`、`t=(1−v)×height−0.5`。最近邻选择 `floor(s+0.5)`；Clamp 限制边界，Repeat 先环绕，支持负 UV。
- 双线性：`C=(1−a)(1−b)C00+a(1−b)C10+(1−a)bC01+abC11`。2×2 红绿蓝白的中心权重各为 1/4，得到 `(0.5,0.5,0.5)`。
- 透视正确属性：`q=Σ(λi qi/wi)/Σ(λi/wi)`。两点 `u=0/1`、`w=1/2`、屏幕权重各 0.5，正确 u 为 `1/3`，直接插值为 `1/2`。世界位置、法线、颜色、UV 都是一般属性；NDC z 保持屏幕线性插值。
- Mipmap：逐级 2×2 平均至 1×1。256 图像共九级。教学实现的奇数尺寸向上取整，边缘块只平均有效像素，例如 3×5→2×3→1×2→1×1。
- LOD：`rho=max(length(dUV/dx×纹理尺寸),length(dUV/dy×纹理尺寸))`，`LOD=log2(rho)`。本章在相邻屏幕位置计算透视正确 UV 的差分来估计导数。足迹 4 texel 对应 LOD=2。
- 三线性：相邻两级分别双线性采样，再按 LOD 小数混合。LOD=0.25 时 `0.75×L0+0.25×L1`。放大限定到基础级，远处限定到最后一级。

## 修改实验参数

每章 `RenderHWxx()` 中的 `PipelineOptions` 控制着色方式、材质、光源、过滤方法和正误对照开关。可以修改 `light.baseColor`、`light.lightPosition`、`light.ambient/diffuse/specular/shininess`。例如 HW40 修改 `gloss.light.shininess` 观察高光宽度，HW44 修改 `MakeModelMatrix` 的尺度。

公共场景在 `Homework/LearningDemos.cpp`：`Render()` 使用 50° FOV；倾斜地面在 `RenderGround()` 设置相机；`CheckerTexture()`、`Ground()` 控制棋盘密度与重复次数。需要手动相机、尺寸和模型时，可以直接创建 `Camera`、`RenderTarget` 并调用五参数 `RenderLearning::DrawMesh()`。修改共享参数会影响使用相同场景的章节，单章实验可以传入自己的数据。

绘图默认在初始化或切章时计算一次，不持续每帧重跑测试。纹理、Mipmap 和常用几何静态缓存；木材纹理只在首次使用时解码。HW50 的基础纹理是程序生成的棋盘格，没有新增第三方依赖。

## 验收与边界

```powershell
cmake --build out/modular --config Release --parallel 4
ctest --test-dir out/modular -C Debug --output-on-failure
ctest --test-dir out/modular -C Release --output-on-failure
```

第五项 CTest `HW32至HW50完整作业` 会逐章运行数值检查、经过真实 Application 调度绘制，并导出 19 张 600×600 PPM，输出目录是 `out/modular/validation/Debug/homework32_50` 或对应 Release 目录。原四项测试继续检查原作业回归、Cube/Teapot、Bunny/Dragon 和下划线资产展示。

渲染目标单边最多 2048，总样本最多 4×1024×1024；图像单边最多 2048，卷积核最大 15×15，球体细分有显式上限。非法索引会明确报错；非有限顶点属性、无效屏幕坐标和退化三角形不进入写缓冲；屏幕包围盒被限制在目标内；原六平面裁剪和严格小于的深度测试继续使用。

学习边界：HW36 为便于逐样本观察，在每个覆盖样本着色，尚未加入常见 GPU MSAA 的着色次数优化。光照是教学 Ambient/Lambert/Blinn-Phong，不包括阴影、PBR 和距离衰减。三线性过滤使用各向同性足迹，斜视地面仍可能模糊；各向异性是后续 HW51。奇数 Mipmap 的向上取整是本实验明确约定。HW51～HW100 不在本次实现范围内；原 HW01 的缺失及 HW12/HW14 的演示状态仍保留。

新的 RGB 图像以线性浮点保存，过滤、抗锯齿与光照在线性空间计算，显示时编码为 sRGB。因此线性 0.5 在窗口中大约是 188，而不是直接量化的 128；数值测试查看线性值。原 HW01～HW31 的颜色路径和图像保持原样。

这些是可重复使用的表面材质，不是现有 Cube、Bunny 等几何模型的原配纹理。没有 UV 的模型在内存生成盒式 UV，所以可能出现投影接缝；源 OBJ 不变。

## Viking Room 配套 OBJ 与颜色图

- 作品：Viking Room；作者：**nigelgoh**。
- 原作品与作者主页链接见下面的官方教程。
- 来源及许可证据：[Khronos Vulkan 教程：Loading Models](https://docs.vulkan.org/tutorial/latest/08_Loading_models.html)。教程标明作品作者及 **CC BY 4.0**。
- 下载镜像：[Overv/VulkanTutorial resources](https://github.com/Overv/VulkanTutorial/tree/master/resources)。
- 许可：[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。请在继续分享模型、贴图或含它们的演示图片时保留本来源、作者与许可说明。
- 文件：`models/viking_room/viking_room.obj` 与同目录 `viking_room.png`；下载原文件保持不变。
- 本项目新增 `viking_room.mtl`，使用 OBJ 原有 `usemtl Texture1` 名称关联配套 PNG，补充 Ka/Kd/Ks/Ns 经典光照系数。
- 本项目渲染时自动居中、等比缩放，并调整演示相机与模型姿态；文档对比图是本软件渲染器的输出。

教程说明该颜色图已经烘焙部分光照，因此再乘 Lambert/布林冯会叠加明暗。它适合检查配套 UV 与贴图读取；研究光照数学时优先使用 plain、gold 或 Poly Haven 表面材质。

## 原有模型与自制预设

`models/cube.obj`、`triangle.obj`、`low_poly_icosahedron.obj`、`stanfordbunny.obj` 是用户原有资产，本次没有重新下载或修改它们；本页不重新指定这些已有文件的许可。

`materials/plain.mtl` 与 `gold.mtl` 是本项目新增的学习预设，无外部贴图。gold 表示经典光照的金色涂层演示，不代表物理金属模型。
